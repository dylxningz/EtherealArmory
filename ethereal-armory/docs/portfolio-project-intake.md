# Ethereal Armory Portfolio project intake

Complete one copy for every potential Portfolio project. Record only verified information. A Shop listing, review, filename, or visual similarity is not proof of project history.

## E. Media checklist

Record this information for every file:

| Filename | Folder/role | Alt text | Caption | Credit | Width | Height | Format | Permission status |
|---|---|---|---|---|---:|---:|---|---|
| | hero / final / working / design / poster / video | | | | | | | |

Media rules:

- Alt text describes useful visual information, not the filename.
- Captions explain context that the image alone cannot communicate.
- Record a credit even when it is “Ethereal Armory” so ownership is explicit.
- Do not place unapproved client media or fabrication masters in the deployed repository.
- Final images belong in `final/`; optional in-progress and design media belong in `working/` and `design/`.
- Images are discovered automatically. Use `project.json` media entries only for optional hero choice, ordering, alt text, captions, credits, or permission status.
