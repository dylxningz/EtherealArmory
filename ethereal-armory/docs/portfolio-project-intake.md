# Ethereal Armory Portfolio Project Intake

Complete one copy of this document for every potential Portfolio project. Record only verified information. A Shop listing, review, filename, or visual similarity is not proof of a project's history.

## A. Minimum required to publish

- [ ] Project title
- [ ] Lowercase kebab-case slug
- [ ] Project type
- [ ] Physical or digital category
- [ ] Creative origin
- [ ] Lifecycle status
- [ ] Completion year or an approved approximate date
- [ ] One clear, approved hero image
- [ ] At least one additional approved final image
- [ ] Meaningful alt text and dimensions for every image
- [ ] Concise project summary
- [ ] Clear statement of what Dylan designed or contributed
- [ ] Clear final outcome
- [ ] Client disclosure status
- [ ] SEO title and description
- [ ] Permission confirmation for every public asset and disclosed identity

## E. Media checklist

Record this information for every file:

| Filename | Role | Alt text | Caption | Credit | Width | Height | Format | Permission status |
|---|---|---|---|---|---:|---:|---|---|
| | hero / final / process / CAD / render / poster / video | | | | | | | |

Media rules:

- Alt text describes the useful visual information, not the filename.
- Captions explain context that the image alone cannot communicate.
- Record a credit even when it is “Ethereal Armory” so ownership is explicit.
- Do not place unapproved client media or fabrication masters in the deployed repository.
